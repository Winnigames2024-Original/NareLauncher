# NareLauncher — сайт

Страница лаунчера: https://winnigames2024-original.github.io/NareLauncher/

Три файла, без сборки и зависимостей:

| файл | что это |
|---|---|
| `index.html` | сама страница |
| `style.css` | оформление, окно лаунчера нарисовано вёрсткой |
| `app.js` | размер и версия из json-ов, появление блоков, поворот головы за курсором |

Выкладывается само: `.github/workflows/static.yml` деплоит содержимое
репозитория на GitHub Pages при каждом пуше в `main`.

## Где файлы лаунчера

Сами сборки и файл обновления лежат в репозитории
[`mods`](https://github.com/Winnigames2024-Original/mods):

- `mods/nareinstaller/NareInstaller.exe` и `install.json` — установщик,
  единственное, что предлагается скачать на сайте;
- `mods/narelauncher/NareLauncher.exe` и `update.json` — сама сборка, по
  этому json обновляется `update.exe` рядом с установленным лаунчером.
  Прямой ссылки на этот exe на сайте нет: лаунчер ставится установщиком.

Эти адреса зашиты внутрь уже разосланных `NareInstaller.exe` и `update.exe`,
поэтому переносить файлы сюда нельзя: у всех, кто уже поставил лаунчер,
сломается автообновление. Сайт просто ссылается туда, чтобы версия была
одна и та же в обоих местах.

## Если менять стили

В `index.html` ссылки идут с `?v=2`. Поднимайте цифру при каждом заметном
изменении `style.css` или `app.js` — иначе браузеры ещё сутки будут
показывать старую версию из кэша.
